## Facts and the remaining clock limitation

Frozen SID `718647188059134933`, ticker DTV, denotes DTE Energy's 2016 Corporate
Units. The frozen issuer/common-stock classification conflicts with that legal
identity; this experiment does not rewrite classification, eligibility or past
selection. Its native terminal is an incomplete `CASH_MERGER` placeholder dated
2019-09-30, reference `actions/delisted`, with no cash or delivery terms.

The [2016 original prospectus](https://www.sec.gov/Archives/edgar/data/936340/000119312516727205/d243567d424b2.htm)
defines purchase-contract settlement on 2019-10-01. The issuer's
[2019 annual report, Note 12](https://www.sec.gov/Archives/edgar/data/936340/000093634020000127/dteenergy2019123110k.htm)
confirms the actual October 1 Treasury release and common-share issuance.
Retained SEC submissions also identify a 2019-10-01 NYSE Form 25-NSE,
accession `0000876661-19-001017`; its XML body remains unavailable. The exact
exchange suspension/last-trade notice has not been admitted. A retained
September 30 quote alone cannot establish tradability. October 1 is supported
as the economic settlement day, and is only a candidate for moving this
placeholder in qualification. The qualification must retain this limitation.

No adjusted settlement ratio, cash interval, fractional rounding group,
coupon attribution or DTE common-share price is inferred. In particular, the
experiment does not reuse DirecTV's 2015 cash acquisition or convert the
approximate 5.87 million issued-share disclosure to an exact per-unit ratio.

## Selected component boundary

Use a typed, immutable P01 proposal bound to the full native term preimage and
the exact own438 outer/inner/state/input/source identities. The packet adapter
removes exactly that term from September 30 and carries the same incomplete
term to October 1, changing only its `session`. It preserves every other
terminal, bar, metadata, sector, benchmark, cash and spin-off field. It fails on
a missing/duplicate/changed preimage, out-of-order use, an existing October 1
DTV event or any other proposed date/security. The placeholder's misleading
native kind is retained as unresolved evidence, not asserted to be the legal
settlement type. There is no terminal evaluator or guard change.

The hosted worker first restores own438 canonically, loads the already
qualified eight original input codecs, and reproduces September 30's original
incomplete leadership cash-terminal refusal. It requires zero canonical
transitions/financial journal commits and an unchanged parent runtime after
that refusal. A fresh canonical restore then attempts the candidate September
30 transition and, if it succeeds, October 1. It records actual before/after
holdings, pending orders, selected leadership, source publications and full
runtime checkpoints. All outputs are explicitly qualification-only wrappers;
no strict outer financial checkpoint or financial journal is written. The
maximum is two canonical component transitions, never account replay.

This directly answers whether month-end reselection changes the DTV roles.
An October 1 incomplete-term refusal remains a useful result and must be
retained. A role-free result does not itself admit the clock as financial
input, prove exchange tradability, or authorize a financial continuation.
Financial integration is a later documented decision using the actual result.

## Hosted containment and evidence

Reuse the exact authenticated own438 artifact, its actual successful worker and
reviewer stop proofs, source/request commitments and admitted client review.
Do not repeat completed accounting/discovery audits. Authenticate ZIP size/hash,
receipt, ciphertext length/hash/GCM and the full inventory before parsing a
checkpoint. The new actual AES-GCM marker roundtrip runs before parent fetch.

One worker uses the existing immutable runtime image, exactly two CPUs and
8 GiB memory with memory-swap equal to memory, network none, read-only root,
no capabilities, no new privileges, bounded PIDs and read-only source/input/
parent mounts. Host admission retains the existing 12 GiB initial disk and
10 GiB pre-worker disk/memory gates. Durable atomic allowlisted phase, resource,
stop and static error-location notes identify failures without public exception
values or financial data. UNKNOWN stop never exports mutable state. Known
stopped output uses the approved seven-day AES-GCM artifact with the key
separate. No blind rerun, automatic financial dispatch, merge or deployment.

Local checks are pure proposal/packet metadata, AST/codecs, marker encryption
and container-inspection stubs. Canonical financial modules are import-fenced
locally. Actual roles and canonical qualification remain unobserved until a
reviewed hosted artifact is available.
