## Frozen candidate R

At each closed session, use the unchanged Core's actual holdings and retained
current holding observations. A security is deteriorating if ANY currently owned
episode for its security ID has BOTH own-episode drawdown <= -10% AND its
21-session return <= -3%. A missing own-drawdown or return is explicitly UNKNOWN
and counts that security's capital as deteriorating; it is never imputed as a
healthy return or price. Record that unknown capital separately. Missing/invalid
prices, unresolved identities or contradictory inventory refuse the screen.

For each security ID, actual aggregate shares times current raw close gives its
marked capital. Count that capital only once, even when two converted ownership
episodes share the security ID. The deterioration score is that marked capital
divided by total Core close equity, including cash and receivables. Use Decimal
representations of the actual recorded quantities/prices/equity for thresholds.

Start inactive before the original 126 formation observations. Enter REDUCED
after any closed-session score >= 30% of Core NAV. While REDUCED, cap the original
baseline's final close target at 55%. Return inactive after the score is <= 15%
on three consecutive closed sessions; intermediate or adverse observations reset
that recovery streak. No portfolio high-water drawdown or old-peak recovery test
is used. R never raises exposure above the unchanged baseline target and never
selects, trims or sells an individual Core holding. The resulting target funds
the next open; prior allocation still bears the intervening overnight return.

These round-number choices are a single first hypothesis, not estimated optimal
parameters. The AND predicate asks for drawdown and negative recent momentum so
ordinary volatile but still positive-momentum winners are not automatically
treated as deteriorating. The release threshold is half the entry threshold,
with a short fixed confirmation instead of G's old-peak restriction. Do not try
alternative thresholds, confirmations or combinations in this screen.
