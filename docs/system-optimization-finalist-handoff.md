# Numerical selection and direct finalist handoff

Numerical search and direct confirmation must admit the same factual basis.
A default path with a separate, independently reviewed finite-interval
equivalence proof keeps its original physical checkpoint and journal lineage.
Direct confirmation must independently bind that same proof through the shared
admission function; calling the physical-only basis reader would incorrectly
reject the already qualified default path.

Accept an optional read-only proof directory for direct confirmation, matching
the numerical worker/reviewer interface. It is not a state transplant or a
waiver. Require the same complete own source, current checkpoint, actual
certificate, canonical prefix review, future-input and factual-file bindings.
Other Core paths remain subject to their own physical admission. No parameter,
classifier, target, funded account equation or training selection rule changes.

Training locks still use only2018-2020 and2018-2022 observations, with the
corresponding later periods withheld from selection. Unknown Core coverage is
explicit; no complete-system optimality claim follows from a partial class.
Direct confirmation runs only on hosted compute, using actual canonical
classifier/controller transitions and every full funded account field. The
selected full2008-origin stock-selection replay remains a separate final gate.
