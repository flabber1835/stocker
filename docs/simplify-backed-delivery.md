# Simplify backed PAPER delivery

The November 11 close and subsequent local install exposed three maintenance
seams in host delivery. The operator-selected software-only installation,
separate financial activation, and plan-preserving backed local patch remain
distinct operations. Preserve signed image and checkout identity, ownership
locks, original deadlines, the saved plan and journal, and backup authority.

Build each local preservation query from explicit trusted clauses for its
handoff mode. Assemble the candidate/predecessor Python probes from named
sections for common observations and the mode-specific proof. The host must
still send the exact qualified program to the selected older image. It cannot
assume the older runtime contains new host tooling. Keep the ordinary scheduled,
completed, retired-cash, blocked-unsent, and successor predicates and their
separate evidence. No additional native reads or broader timing windows follow
from this refactor.

Select activation parser, configuration class, deployment class and literal
environment writer directly in the owned operation. Use the same existing
certified software verifier and exact image selection. SHADOW can never obtain
broker or signing credentials from PAPER configuration. Preserve the native
activation checkpoint and the exact compare-and-write rule for environment
updates. The canonical software install is still fenced and still independently
verifies the release.

When a maintenance handover starts from an already authenticated, running host
selector and the matching deployment selector is absent, carry its exact signed
selection into this deployment under the handover's owned preparation. Verify
the runtime receipt, both source/environment identities, and native process
ownership before publishing the missing record. A conflicting, aliased, or
malformed record refuses. Both selector scopes and retained before/after bytes
still participate in the normal handover and rollback.

Qualify the existing handoff cases, changed-state and deadline refusals, same
observation validation, certified image and activation separation, guarded
environment writes, and idempotent native selector carry-forward. Use private
fixtures and preserve historical operation receipts.
