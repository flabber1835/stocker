# Recurring backup work admission and archive I/O

The ordinary maintenance pass obtains the day's XNYS open and close from the
release image's pinned exchange calendar alongside the selected base metadata.
Reserve the hour before open, the session, and the hour after close for data
publication and preparation. On holidays and weekends the exchange reserves
no interval. Outstanding leased close work can extend the reservation.
Calendar unavailability defers discretionary work. Fresh chain publication
and continuity checks run on every pass regardless of market activity.

The usual daily and 24-hour base triggers may wait. A timeline advance,
the proactive WAL footprint threshold (including the object ceiling), or
an approaching hard base age requires a successor even during a reservation.
Allow the base command and a maintenance cadence before the age limit.
Continue deferring discretionary cleanup and retention after that successor.
Installation and operator recovery keep their existing entry points.

For WAL publication, bind PostgreSQL's source to its device, inode, size,
modification and change times before reading its cluster identity. Hash its
bytes, copy to private media, fsync and verify the temporary copy against that
digest before promotion. Verify the actual winning final before issuing a
sidecar, and recheck both the final and source after syncing the published
pair and directory. Atomic no-clobber publication, matching-winner retry,
and refusals for divergent data or checksum apply to every object type.

The native Python 3.8.15 supervisor owns at most one callback per child. Cancel
that future if still queued and join the executor during cleanup. A callback
failure is reported after the child finishes. Exercise that path with an
actual child and callback on the minimum supported interpreter.

## Provider qualification boundary

The resource, integrated rehearsal and GO fixtures use the maintained Alpaca SIP and OpenFIGI wire shapes. Only read-only GETs for assets, SIP bars, corporate actions and POSTs for identifier mapping are routed to a private synthetic server. The provider clients retain their validators, pagination, normalization and evidence generation. The test runner supplies dummy credentials. Host certification and backup authority run independently of this synthetic data. Qualification records real requests to all four endpoints and verifies a replay does not download price pages again.
