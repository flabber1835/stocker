# Research proof of the complete controller outcome

The frozen P02 continuation stopped on August 23, 2023 while proving the
leadership return comparison against `LDRC_R20 = -0.085`. The original proof
requires every executed comparison of an uncertain return to have the same
Boolean result throughout its interval. That condition is sufficient for an
unchanged controller outcome, but it is not necessary. A later conjunct can
make an earlier ambiguous comparison irrelevant to the complete result.

This is a research proof refinement. It must not change the frozen controller,
Core, financial source, prices, intervals, original model files or parameters.
It must not pick a contingent-right value or suppress a real decision change.
No production or local canonical execution is authorized.

## Admission and scope

First authenticate and independently inspect the stopped Chinook artifact,
including its actual refusal, inputs, checkpoints, certificate seed and tails.
A negative SPY return calculated from the frozen benchmark is preliminary
evidence only; it does not replace the actual controller inputs in that
artifact. Preserve the original comparison refusal in every case.

If the actual inputs confirm that a proof refinement is applicable, bind the
new proof implementation and contract through a separate, strictly typed
research input to that arm's exact admitted predecessor. Retain all existing
input descriptors and source-evidence bytes. The new input changes no market
packet. It declares the stronger outcome-level admission argument explicitly;
it must not silently reinterpret an old certificate that claimed individual
comparison invariance.

## Complete bounded branch proof

Call the unchanged canonical recovery function on private copies of the same
complete inputs. Comparisons whose interval endpoints agree retain their
existing proof. At an ambiguous comparison, explore both Boolean outcomes,
including both short-circuit paths. Continue until every leaf has completed.
Refuse unsupported scalar arithmetic, an unhandled comparison, an unexplored
leaf, an exceeded explicit branch bound, or mutation of the original inputs.

The exploration may overapproximate the jointly feasible comparison paths.
That is conservative: admission requires every explored leaf to return the
same complete canonical state and decision as the ordinary representative
call. Equal target exposure alone is insufficient. Latched flags, counters,
audit state, reasons and every returned field must also match. If any complete
outcome differs, preserve the counterexample and refuse. Neither a chosen
branch nor a point contingent-right estimate is an admissible fallback.

The representative and all existing interval arithmetic retain their original
roles. This proof adds no forecast, expected return, probability, holding mark
or contingent payment. Existing position, pending-order, intent, event-source,
source-binding and journal guards remain mandatory.

## Evidence and continuation

Use a distinct certificate proof mode. Record all comparisons, branch choices,
leaf counts and complete-result commitments. Old certificates remain byte
identical. New summaries must distinguish individual comparison invariance
from complete controller outcome invariance; never label an ambiguous
comparison invariant.

Hosted qualification must exercise the actual frozen controller with a masked
ambiguous comparison, a genuinely outcome-changing comparison, latent-state
differences, input mutation and branch-limit refusals. Verify a guard-removal
falsifier. Pure callable fixtures are useful implementation checks but are not
canonical integration evidence. Independent stopped-book review must repeat
the full branch proof for each new committed row, alongside all existing
accounting, restoration, source, input, prefix and recovered-tail checks.

Advance only the exact own suffix after admission and qualification. Preserve
every prior failure and uncertain result. This does not authorize a restart,
policy change, controller optimization, fabricated value or production change.

## Witness frame and dependency condition

The complete-result comparison holds the supplied valid controller frame
fixed while exploring every Boolean outcome of the two bounded return inputs.
It does not assert that the uncertain witness NAV history has one numerical
value. Existing interval propagation continues to carry that uncertainty.

The frozen recovery binding copies and validates the full frame, but constructs
its Candidate A snapshot only from recovery flags, counters, prior allocations
and audit counts. Candidate A receives the bounded returns as separate scalar
inputs. Recovery does not derive another return or a trading choice from the
copied witness history, selected names, marks or peer history. Qualification
must bind this dependency claim to the actual frozen source and verify that
these frame fields are copied unchanged. A controlled alternative positive
witness frame must preserve the same decision and recovery state; this test
does not establish a different historical valuation.

Each new certificate retains the commitment of the complete actual controller
input frame and the input itself, alongside the branch proof and original
rolling interval state. The input is captured at the actual recovery call;
its state identity and scalar observations are bound by the certificate's
existing financial-row and watch commitments. The stopped-book reviewer
reconstructs the exact proof call from these inputs, checks the recovery
projection against the preceding committed state, and checks the observed
returns against the financial row and independently reconstructed intervals.
It must verify frame copying and compare complete results using that frame,
rather than treat a fresh placeholder frame as the complete historical state.
The logical-state projection remains an additional induction check, not a
replacement for this complete-input proof.
