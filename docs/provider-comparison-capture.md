# Retired provider comparison capture

The optional dual-provider capture/preprocessing commands and the standalone
legacy membership probe were retired on 2026-10-17. They are not current
installation, activation, automation, or CI requirements.

Existing capture files and historical audit evidence remain unchanged. The
independent price/volume-basis tests and current Alpaca read-only autonomy
diagnostics remain supported.

See [the current Alpaca/OpenFIGI source contract](alpaca-go-cold-start.md) and
[CI suite hardening](ci-suite-hardening.md) for the active preservation boundary.
