# Owned55 numerical study on the retained Sharadar replay

## Decision and scope

Use the already audited February 22, 2008–July 31, 2026 Core history. The
repository preserves Sharadar for historical research. Production GO uses
Alpaca/OpenFIGI; this study does not certify that production source or restore
Sharadar to GO. No new vendor request, production database access, Core replay,
PAPER change or deployment is needed. Preserve the incomplete Alpaca work and
every prior negative/refused result as separate evidence.

The original four-axis/108-setting restriction was a runtime compromise, not a
scientific reason to freeze the other thresholds. Include all nine existing
numeric Owned55 rule fields in one predeclared coarse finite class. This tests
parameter changes within the existing architecture; it does not optimize all
possible trading architectures or promise a joint CAGR/drawdown improvement.

## Chronology and selection

Propagate each private canonical controller from its own cold state through
all 126 retained formation observations and the measured history from 2008.
Earlier observations initialize the state and account; select using only
January 2, 2018–December 30, 2022 performance. Use the last 2017 close as the
training NAV/drawdown anchor. Report all five training years separately.

Freeze the shortlist before processing candidate financial results for
2023–2024. Report those evaluation years jointly and individually, followed by
2025–July 2026 as a later diagnostic. All periods are known history; previous
research has inspected portions of them, so do not call them unseen/OOS.

Use a Pareto growth/drawdown objective, not a fitted weighted error with an
arbitrary hidden weight. Select the highest training growth under drawdown
budgets 50%, 75% and 100% of baseline drawdown, plus the highest-growth strict
joint improvement if one exists. Break exact growth ties by lower turnover,
then baseline preference, then configuration ID. At most four unique choices.
Retain baseline, all training scores, Pareto tradeoffs and annual stability.
Identical economic paths are equivalence classes, not extra evidence. No
selection or retuning may use evaluation/diagnostic performance. A finite-class
optimum is conditional on this family, data and accounting model, not a global
optimum over trading systems. Preserve null/negative findings.
