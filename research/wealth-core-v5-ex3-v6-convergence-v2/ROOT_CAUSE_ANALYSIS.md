# Wealth Core V5 + Sentinel EX3 V6 convergence V2 — root-cause analysis

Date: 2026-09-09

Experiment run: `34433683463`
Pinned experiment head: `0db55ee8feff132b033f233a0b5ab5dd5b9a65fa`
V6 published authority: `96f705c3b699ec283dbac7e93b973dba9769f038`
Selected V6 config: `rec=8, r40_floor=-0.04, fast_damaged=0.88, healthy_damaged=0.63`
Measurement: 2006-07-31 through 2026-07-31, 5,032 sessions, broad full-PIT universe.

## Executive conclusion

The Stage-3 automated label `SENTINEL IS NOT THE PRIMARY BUTTERFLY SOURCE` is not a valid causal conclusion from the V2 experiment and must not be used as the final source-attribution verdict.

The evidence supports a three-layer causal chain:

1. **Wealth Core is the initiating source of path diversity.** Every controller divergence is preceded by a Wealth Core portfolio/NAV-path divergence. In the LOO cases that later change Sentinel, the excluded security itself is already gone 213–928 calendar days before the first Native target divergence, so the later effect is an endogenous Wealth Core path-memory cascade rather than continued direct exposure to the excluded name.
2. **Native Sentinel is a material amplifier.** Path-specific Wealth Core NAV/high-water history moves the Native ordinary/base/slow episode timing and recovery ramp. Of 1,445 Native target-difference sessions across the five affected screen cases, 1,318 (91.21%) occur while the two paths have identical current `fast_signal` and `slow_signal` booleans. The output difference is being carried by live hysteresis state. Approximately 47.2% of Native divergent sessions are severe-state mismatches and 52.8% are recovery-ramp phase mismatches.
3. **EX3 adds a second material amplification layer.** Across the five affected cases, 785 of 2,132 allocation-difference sessions (36.82%) remain even when the two paths' effective Native allocation is already equal. Exact one-step counterfactual reconstruction shows that substituting the baseline EX3 behavioral pre-state into the perturbed path resolves 1,477 of 2,133 decision differences (69.25%); the recovery-memory group alone resolves 56.17%, and latch memory resolves 13.13%. These interventions are diagnostic and non-additive, but they establish that EX3's active memory is causal.

The correct current conclusion is therefore:

> **The butterfly originates upstream in Wealth Core path dependence, then is materially amplified by economically active Native slow/ramp hysteresis and EX3 episode/latch persistence. V2 rules out redundant/future-inert state as the mechanism; it does not rule out Sentinel as an amplifier.**

No production change is justified by this RCA. Any attempt to reduce active-state sensitivity is a controller-economics redesign and requires separate research/certification.

## 1. Why the Stage-3 automatic verdict is too strong

`aggregate_v2.py` defines V2 success as a reduction in Native or final allocation divergence. When neither improves, it assigns `SENTINEL IS NOT THE PRIMARY BUTTERFLY SOURCE`.

That implication is invalid because V2 was deliberately constructed as a semantic quotient: authoritative output is computed first, and only state distinctions proved future-inert are normalized afterward. If those equivalence proofs are correct, V2 should not alter future outputs. A null behavioral effect therefore means only that the canonicalized state distinctions were not causal to behavior.

It does **not** distinguish between:
- butterfly behavior generated by Wealth Core alone; and
- butterfly behavior generated by live, economically intentional Sentinel hysteresis responding to a Wealth Core perturbation.

The final V2 workflow job did not perform an independent causal attribution after Stage 4 was skipped; it copied the Stage-3 screen summary into the final summary. Treat the old label as a funnel label, not a validated RCA verdict.

There is also a minor funnel-spec discrepancy: the implemented screen proceeds on any strict improvement above numerical tolerance, whereas the planning brief described a material (~10%) hurdle. This did not change the outcome because V2 produced exactly zero behavioral improvement.

## 2. What V2 actually proved

Baseline economic safety was exact:
- Native target difference sessions: 0
- allocation difference sessions: 0
- maximum absolute NAV difference: 0
- Native V2 canonicalization was exercised thousands of times
- EX3 V2 canonicalization was exercised thousands of times

V2 also substantially collapsed irrelevant Native state inequality without changing output. Across the seven screen cases, the median fraction of sessions with unequal raw Native state was about 90.8%; after V2 semantic canonicalization it fell to about 29.1%. EX3 state inequality changed much less (median about 9.64% to 9.46%).

This is strong evidence that:
- a large amount of Native's raw state difference was representational/noise-like;
- V2 successfully removed much of that noise;
- the remaining behavioral divergence lives in state that V2 intentionally preserved because the authoritative transition function still consumes it.

So V2 succeeded as a **state simplifier**, but failed as a **behavioral convergence treatment**. Those are different claims.

## 3. Wealth Core is the initiator

Stage-3 perturbations were six deterministic held-security LOO cases plus one deterministic 1% universe-dropout case.

The commonly quoted `median_core_divergence = 80.7%` is a binary exact-set measure: it counts a session as divergent if even one holding differs. It must not be interpreted as 80.7% of holdings being different.

Actual portfolio-distance context:

| Case | Sessions with any holding-set difference | Mean symmetric name difference | Mean Jaccard | Native divergence | EX3 divergence |
|---|---:|---:|---:|---:|---:|
| LOO 0 | 65.5% | 3.41 | 0.841 | 3.12% | 6.00% |
| LOO 1 | 99.6% | 5.97 | 0.731 | 7.35% | 9.64% |
| LOO 2 | 80.7% | 3.42 | 0.837 | 4.97% | 7.59% |
| LOO 3 | 90.5% | 6.64 | 0.700 | 5.72% | 7.89% |
| LOO 4 | 2.40% | 0.043 | 0.997 | 0 | 0 |
| LOO 5 | 4.83% | 0.089 | 0.995 | 0 | 0 |
| 1% dropout seed 11 | 92.4% | 5.76 | 0.735 | 7.55% | 11.25% |

LOO 4 and LOO 5 are important controls: Wealth Core can follow a different portfolio path without causing any Sentinel divergence at all. Therefore exact portfolio non-convergence is not sufficient to trigger controller non-convergence.

For the four early LOO cases that do affect Sentinel, the excluded security stops being held 213–928 days before the first Native divergence. This establishes a path-memory cascade inside Wealth Core. Relevant mechanisms in the pinned V5 runner include:
- per-position trailing peaks and the 70% stop threshold;
- the one-time 119-session review;
- 21-session slot/security cooldowns;
- post-initialization admission limited to one ready vacancy per day;
- ranking/eligibility and issuer exclusion;
- 5%-of-NAV sizing and cash availability;
- persistent cash/receivables and vacancy chronology.

One replacement can therefore change its own peak/exit date, the date a vacancy becomes reusable, which ranked candidate is available on that day, position sizing/cash, and subsequent replacement chronology. This is legitimate economic path dependence in the current Wealth Core mechanics.

## 4. Native Sentinel is a real amplifier

Native is not responding only to current cross-sectional evidence. It has active episode memory:
- `ordinary` starts at WC drawdown <= -15.5%;
- a base episode stores `base_anchor` and `base_dur`;
- slow defense requires base duration >=30 plus since-anchor return <= -2%, WC R40 <= -3%, damaged breadth >=75%, and green breadth <=25%;
- fast/slow severe state outputs 0;
- recovery may enter a 55%/65% ramp whose duration depends on continuing health evidence.

Across the five affected cases there are 1,445 Native target-difference sessions. The conditional mean absolute target difference is large (roughly 0.56–0.73 depending case), so these are not tiny numerical discrepancies.

Absolute target-difference area (`sum(abs(target_base-target_case))`) by affected case is 115.2, 255.25, 141.3, 193.25 and 256.95 allocation-session units.

The key decomposition is:
- 91.21% of Native target-difference sessions have the same current `fast_signal` and `slow_signal` booleans on both paths;
- 47.2% are explained by one path being in severe fast/slow state while the other is not;
- 52.8% have the same severe/non-severe status but differ in recovery-ramp state/phase.

Thus the current trigger is usually no longer different when the target remains different. Active hysteresis is carrying the effect.

### Case study: 2010-05-28, LOO 0

At first Native divergence:
- holdings sets: identical;
- damaged breadth: identical (77.78%);
- green breadth: identical (22.22%);
- recent-leadership R20/R40: identical;
- SPY R20: identical;
- WC drawdown: -23.98% vs -24.09% (only ~11 bp apart);
- Native target: 0 vs 1.

The causal difference is earlier episode history. Baseline crossed the ordinary-DD episode threshold on 2010-04-16; the case crossed on 2010-04-27. On 2010-05-28 the baseline base duration is 31 sessions and qualifies for the slow trigger, while the case duration is only 24. This converts an upstream path-timing difference into a binary 0/100% target difference even though the current portfolios and major observed breadth/leadership inputs have reconverged.

That is direct evidence of Native hysteresis amplification.

The first Native divergence in all five affected Stage-3 cases is tied to the slow/recovery pathway, not a fresh fast entry. Native differences occur in discrete stress clusters (2008-09, 2010, 2011, 2015-16, 2018-19, 2020, 2022, 2026), not continuously. All seven Stage-3 Native paths are terminally reconverged by the end of the test.

## 5. EX3 adds further persistence

EX3 V6 has its own live memory:
- an `episode` starts when Native moves from full to defensive;
- when Native returns to full, EX3 can continue holding the previous desired exposure until recovery is certified;
- `latched` can enter when Native/effective Native are full while WC drawdown <= -10%, recent-leadership R20 <= -8.5%, and SPY R20 >=0;
- a latch caps desired exposure at 55% until an 8-session full-health recovery or strong SPY rebound clears it.

Across affected cases, EX3 increases divergence duration and integrated area:

| Case | Native diff sessions | EX3 diff sessions | Native abs-diff area | EX3 abs-diff area | Area ratio |
|---|---:|---:|---:|---:|---:|
| 0 | 157 | 302 | 115.20 | 199.65 | 1.73x |
| 1 | 370 | 485 | 255.25 | 335.40 | 1.31x |
| 2 | 250 | 382 | 141.30 | 230.80 | 1.63x |
| 3 | 288 | 397 | 193.25 | 242.75 | 1.26x |
| 1% dropout | 380 | 566 | 256.95 | 360.80 | 1.40x |

In total, 785/2,132 (36.82%) EX3 allocation-difference sessions occur while the two paths' effective Native allocation is already equal. This is a clean measure of additional EX3 persistence beyond current Native allocation differences.

An exact one-step reconstruction of CandidateA matched every recorded transition in the screen. Diagnostic same-date pre-state substitution on the 2,133 close-decision differences gives:
- all EX3 behavioral pre-state aligned: resolves 69.25%;
- recovery memory (`episode`, `recent_positive_streak`, `prev_desired`, `prev_native`): 56.17%;
- latch memory (`latched`, `full_streak`): 13.13%;
- current Native target alone: 50.59%;
- current WC evidence alone: 1.27%;
- all current inputs aligned: 52.04%.

These counterfactual categories overlap and are not additive. They nevertheless show that historical EX3 behavioral state is a major carrier of divergence.

### Case study: EX3-only latch beginning 2021-12-08

On 2021-12-08 baseline and all five affected comparison paths have Native=1 and effective Native=1. Recent-leadership R20 is roughly -9.9% and SPY R20 is +0.46%, satisfying those latch surfaces. The baseline WC drawdown is -10.997%, crossing EX3's -10% latch threshold. The comparison paths have WC drawdowns from about -5.9% to -8.5%, so they do not latch.

Baseline then remains latched from 2021-12-08 through 2022-08-10 (169 sessions), while those comparison paths omit that latch. This is an explicit EX3 amplification mechanism triggered by path-specific WC drawdown even when Native itself is equal.

## 6. V1 is a useful causal intervention — and a warning

V1 was not a safe semantic quotient. It added a new release rule: after eight neutral/full-Native sessions it could clear active `episode`/`latched` state and force desired exposure back toward Native.

That intervention materially reduced divergence in the representative LOO 0 case:
- authoritative EX3 cross-path divergence: 302 sessions;
- V1 patched cross-path divergence: 198 sessions;
- 105 previously divergent sessions were removed and one new divergent session was created.

The removed divergence was concentrated in long 2022 recovery/latch persistence intervals.

But V1 also changed the unperturbed baseline on 202 sessions. Baseline economics deteriorated materially:
- authoritative V6 CAGR: 21.56%; V1: 19.71%;
- authoritative V6 max drawdown: -27.38%; V1: -35.39%;
- authoritative V6 Sharpe: 1.121; V1: 1.021.

This is highly informative causally: weakening active controller memory can improve path convergence, proving that active Sentinel state contributes to the butterfly. But that same memory carries economically valuable defensive behavior. Convergence cannot be optimized independently of economics.

## 7. Timing-harness observation

The generated research source calls EX3's close-decision function before updating the local `effective_native` variable to that day's opened Native target. By source order, the EX3 decision receives a one-session-staler effective-Native variable than the row later records.

This is a latent timing-contract concern and should be hardened in future research instrumentation. However, exact recursive replay from the measured-state boundary using the recorded versus corrected effective-Native input produced zero decision/state differences on the baseline and all seven Stage-3 paths. Therefore this ordering does **not** explain any observed V2/Stage-3 result.

## 8. What remains unresolved

The current evidence establishes origin and amplification, but does not yet establish whether the active Native/EX3 hysteresis is *too sensitive* economically.

The seven-case screen was selected to test V2 treatment effect efficiently, not to provide a statistically complete causal attribution across the perturbation distribution. Stage 4 was intentionally skipped after V2 showed zero behavioral effect. The source-attribution question therefore needs a dedicated experiment rather than reusing the V2 funnel label.

The next research-only experiment should use the full perturbation set and perform explicit state ablations:

1. Native component attribution: independently align `base_anchor`, `base_dur`, ordinary/base episode timing, slow state, fast state, ramp state and recovery history on a same-date diagnostic tape.
2. EX3 attribution: independently test recovery episode memory, latch memory, and all behavioral state, while separately controlling the Native input.
3. Threshold-margin analysis around Native DD -15.5%, slow duration 30 / since-anchor -2% / R40 -3% / breadth thresholds, and EX3 DD -10% / recent-leadership R20 -8.5%.
4. Exogenous controller-state perturbation while holding the Wealth Core observation tape fixed, to measure Sentinel's autonomous sensitivity independent of portfolio selection.
5. Measure integrated allocation-difference area and economic dispersion (CAGR, MDD, Sharpe), not only binary session divergence.
6. Use all 16 deterministic LOO and all three fixed 1% universe-dropout cases; add randomized dropout seeds only if the fixed campaign leaves material uncertainty.

Until that attribution study is complete, do not promote V1, V2, or any new convergence behavior into production.
