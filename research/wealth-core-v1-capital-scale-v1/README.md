# Wealth Core V1 capital-scale diagnostic

Frozen diagnostic of Wealth Core V1 at smaller starting-capital levels. The certified $100M replay remains the external control. This research changes only initial book cash and adds read-only telemetry for whole-share and cash-limited admission mechanics. Sentinel is excluded.

Preregistered starting capitals: $100,000; $1,000,000; $10,000,000.

Primary questions:
- Does V1 performance/path materially change with starting capital?
- How often do integer-share `q=0`, one-share, cash-limited, next-open clipping, and underfunded-entry events occur at each scale?
- Is the current $100M control representative of the user's ~$100k deployment scale?

No threshold is tuned from outcomes. The $100M certified V1 result is not rerun here; it is the frozen control.
