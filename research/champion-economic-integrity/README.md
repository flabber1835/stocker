## Findings established

**The certificate reintroduces an unintended capacity rule.** It defers an entire order above 10% of prior-20-session volume, provides no capacity-sized partial progress and retains the pending request. The pinned Production execution path omits this rule; corrected closure removed it; the earlier user handoff prohibited its reintroduction. A capital change is not the corrective action established by this audit.

**Classification creates the first decision difference on July 5, 2006.** The candidate admits 1,102 eligible securities and the certificate 837. The third admission differs. The classifier-only control proves this independent causal axis. Candidate historical-type authority remains provisional; its exact method applies PDS evidence dated June 2010 to July 2006.

**Capacity creates a separate fill difference on July 6, 2006.** The identical 205,028-share MED request exceeds the certificate's 132,440.5-share ceiling. The certificate defers it. Removing only that ceiling produces 25 holdings and $4.64 residual shadow cash at the prefix endpoint; the certificate retains 18 holdings and $27.99M cash.

**Both generated paths contain a dividend/open-equity defect.** They post the current ex-date receivable after calculating the open-equity witness used by the allocation overlay. Exact-source synthetic fixtures demonstrate incorrect return attribution when allocation changes. Historical CAGR impact has not been measured.

**Some certificate labels exceed their demonstrated evidence coverage.** The exact collector returns financial/checkpoint PASS labels from two declaration files, with no replay, ledger or exercised checkpoint. The fixture passed on Python 3.12.14 in run 34043631885. This finding concerns the collector, not the complete finalizer. The existing dynamic causality test target is the pinned Production kernel, which differs from the generated Champion program.
