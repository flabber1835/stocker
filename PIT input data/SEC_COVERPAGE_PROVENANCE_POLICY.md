# SEC cover-page provenance policy

Every accepted security-type evidence row must retain:

- Orion ticker
- Orion decision/buy date being certified
- SEC CIK
- CIK retrieval source (causal SEC evidence preferred; non-PIT maps only as retrieval hints)
- SEC filing date
- form type
- accession number
- primary document
- evidence strength
- security-title snippet
- source URL

Classification authority comes only from the historical filing content and its filing date, never from the retrieval hint used to locate the issuer.
