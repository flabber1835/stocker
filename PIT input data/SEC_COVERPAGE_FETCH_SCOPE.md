# SEC filing retrieval scope

Target forms for unresolved security-type evidence:

- 10-K / 10-K/A
- 10-Q / 10-Q/A
- 20-F / 20-F/A
- 40-F / 40-F/A
- S-1 / S-1/A
- F-1 / F-1/A

Only filings with `filing_date < Orion decision/buy date` may supply positive evidence. The first retrieval pass is limited to the 149 buy rows left unresolved by the Form 3/4/5 security-title analysis.
